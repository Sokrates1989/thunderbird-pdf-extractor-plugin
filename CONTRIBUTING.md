# Contributing

Thank you for improving PDF Archiver for Thunderbird. Fork the repository, create a focused branch, and open a pull request against `main`. Discuss broad features, protocol changes, and compatibility-breaking work in a GitHub Issue first.

## Development checks

Run the extension checks from `extension/` and native-host checks from `native-host/` as documented in the [README](README.md#development-validation). Installer changes additionally require the disposable macOS or Windows installer test for that platform.

Keep German and English user-facing text synchronized. Do not commit real email, attachments, output documents, local paths, profile data, credentials, virtual environments, or generated installers.
