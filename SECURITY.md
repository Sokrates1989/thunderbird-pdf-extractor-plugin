# Security Policy

## Supported versions

Security fixes are provided for the latest published release. Users should update the extension and matching native companion together.

## Reporting a vulnerability

Do not disclose exploitable vulnerabilities, private email, attachments, generated documents, credentials, or local paths in a public issue. Send a minimal report to `thunderbird-pdf@felicitas-wisdom.com` with the affected version, platform, impact, and reproduction steps using synthetic files.

The maintainer will acknowledge a usable report, investigate it, and coordinate a fix and disclosure timeline. No monetary bug bounty is currently offered.
